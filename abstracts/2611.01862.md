# Interoperability Assessment of Fronthaul and E2 Interfaces for Multi-Vendor Open RAN Systems

**Authors:** Farhad Mehran, Charles Turyagyenda, Dritan Kaleshi

Open Radio Access Networks (RANs) aim to transform the existing wireless network architectures by adopting open interfaces, disaggregating and virtualising RAN components, and enabling dynamic control of the system via data-driven methods. To accelerate the development of interoperable RAN solutions, rigorous assessment of Open Fronthaul and E2 interfaces based on O-RAN Alliance Interoperability Testing (IOT) specifications plays a key role as the integration of these interfaces seems to be very challenging, e.g. due to the need for alignment of Fronthaul IOT profiles and unforeseen challenges for E2 interface integration as Near-Real-Time RAN Intelligent Controller (Near-RT RIC) is relatively a new component introduced within the RAN architecture. In this paper, selected parts of the latest findings and lessons learned from interoperability assessment of Open Fronthaul and E2 interfaces for 13 multi-vendor Open RAN systems deployed in SmartRAN Open Network Interoperability Centre (SONIC) Labs are presented.
