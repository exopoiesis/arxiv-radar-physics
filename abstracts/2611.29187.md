# CLFF: Automated Framework for Concurrent Learning Force Fields and Material Property Calculations

**Authors:** Cao Thang Nguyen, Sung Youb Kim

Machine learning interatomic potentials (MLIPs) offer an efficient paradigm for large-scale atomistic simulations with near first-principles accuracy. However, developing and deploying these potentials often involves intricate procedures that require substantial manual effort and domain expertise. In this work, we present CLFF, an open-source Python framework designed to automate concurrent learning workflows for MLIPs. CLFF integrates model training, MLIP-driven sampling, uncertainty-based candidate selection, quantum-mechanical labeling, and dataset augmentation into a unified workflow. The framework currently supports several modern graph-based MLIP architectures and is compatible with widely used computational chemistry and materials science tools. A distinguishing feature of CLFF is its ability to asynchronously distribute computational tasks across multiple heterogeneous remote computing resources, enabling users to aggregate fragmented hardware infrastructure within a single controllable workflow. In addition to concurrent learning, CLFF provides automated workflows for initial data generation and material property calculations, including phonon dispersion and potential energy surface scans. By minimizing manual intervention and enhancing reproducibility, CLFF offers a flexible platform for developing and deploying MLIPs in computational materials research.
