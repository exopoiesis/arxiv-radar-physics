# NuSrcAgent: An AI Agent for High-Energy Neutrino Source Searches

**Authors:** Bei Zhou, Po-Wen Chang, Kohta Murase

Identifying the sources of high-energy cosmic neutrinos is crucial for understanding cosmic particle accelerators and probing new physics. IceCube provides public data that allow researchers to search independently for neutrino sources, but these analyses require substantial technical expertise and careful scientific choices. We present \system, the first publicly available AI agent for high-energy neutrino source searches. Compared to public likelihood codes, \system is easier to install and use, and supports more analysis types. To start an analysis, users need only specify a source or catalog. The agent takes natural-language requests, runs likelihood analyses on public IceCube event data, and saves the settings and calculation records so users can repeat the analyses. We demonstrate \system through single-source and catalog stacking analyses, obtaining results consistent with IceCube results. These examples also show its ability to search the literature, analyze non-power-law spectra using user-provided model code, and develop new analysis functions, such as signal-injection simulations. \system is also a powerful tool for improving and testing existing analysis code, as we demonstrate by using it to refine the background probability density functions and reduce residuals and spurious signal contributions in stacking analyses. \system makes high-energy neutrino data analysis more accessible to the broader research community.
