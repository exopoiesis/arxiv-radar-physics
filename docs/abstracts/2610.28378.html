Topology-Adaptive Seismic Response Prediction of Interconnected Structural Systems Using Reduced Order Model Embedded Graph Neural Network

Huangbin Liang, Beatriz Moya, Francisco Chinesta, Eleni Chatzi

arXiv:2610.28378·eess.SP·Published 2026-10-20

Electrical substation equipment is commonly interconnected by busbars and flexible conductors. Such interconnected infrastructures exhibit complex dynamic interactions, where the response of each component is influenced by local structural properties, mechanical coupling, system topology, and transient excitation. High-fidelity FE models can capture some of these effects, but their computational cost limits their use for real-time prediction. Purely data-driven models offer faster inference, yet they struggle to generalize, requiring additional simulations and retraining for each new configuration. This work presents a ROM embedded Graph Neural Network (ROMeGNN) for topology-aware seismic digital twins of interconnected structural systems. The system is represented as a graph, where structural components are treated as nodes and mechanical interconnections as edges. Each high-fidelity component model is first reduced to a reduced-order modal representation, which forms a differentiable dynamics operator within the GNN. Rather than learning the full response directly, the GNN estimates topology-dependent interaction forces that enter the differentiable ROM solver as coupling inputs for modal state advancement. This hybrid formulation preserves the known component-level physics and uses data-driven message passing to learn complex inter-component forces across varying system layouts. The framework is demonstrated on interconnected electrical substation equipment subjected to randomized seismic inputs. It delivers rapid predictions of response quantities relevant to seismic damage assessment while remaining applicable across varying layouts, component combinations, and excitation scenarios. These results highlight the potential of embedding physics within graph learning architectures for real-time, interpretable, topology-adaptive seismic digital twins of interconnected engineering systems.
