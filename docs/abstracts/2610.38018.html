Regularizing the Navier-Stokes Equations via Additive Type Noise plus Small Linear Multiplicative Noise

Weiquan Chen

arXiv:2610.38018·math.PR·Published 2026-10-27

We derive a series of ``regularization by noise in high probability" results for incompressible Navier-Stokes equations $(d\geq3)$, via a new mechanism based on fixed point argument: For initial values in critical Besov space $\dot{B}_{q,\infty}^{-1+d/q}~ (1\leq q<\infty)$, we can expect unique global solutions with $C_{w^*,loc}\big([0,\infty);\dot{B}_{q,\infty}^{-1+d/q}\big)$-paths in high probability if the equations are perturbed by well-constructed additive type noise; for initial values in the ``end-point space" $\dot{B}_{\infty,\infty}^{-1}$ where the equations are locally ill-posed in deterministic setting \cite{BP08}, we can still expect unique solutions on $[0,T]$ (with ``modified" $*$-weak continuous paths) in high probability for large enough $T>0$, if the equations are perturbed by a well-constructed additive type noise plus a ``small" linear multiplicative noise. This means that the regularizing effect can be strengthen by small additional linear multiplicative noise in the sense that the Picard iteration remains effective for values in the largest critical space $\dot{B}_{\infty,\infty}^{-1}$. This work has nothing to do with AI models.
