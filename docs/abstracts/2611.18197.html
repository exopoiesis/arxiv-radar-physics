Data-Driven Sparse Identification and Robust Tube-Based Predictive Control for Multivariable Chaotic Systems

Shahin Razani

arXiv:2611.18197·eess.SY·Published 2026-11-13

This paper addresses the data-driven synchronization and robust control of multivariable chaotic systems subject to strict actuation constraints, modeling uncertainties and bounded input disturbances. Using empirical data collected from a four-dimensional chaotic Rossler response system, Sequentially Thresholded Least Squares (STLSQ) sparse regression is employed to recover a nominal control-affine model, achieving an identification accuracy of R^2 = 1.0000 across all channels with root-mean-square error within [4.15e-6, 8.33e-4]. To establish a mathematically rigorous bridge between data-driven identification and robust synthesis, all structural discrepancies in the drift vector field and input matrix are unified into a single lumped uncertainty field delta(x,u). A computable scalar bound delta_bar is established based on library truncation error, regression residuals, input bounds, and Lipschitz constants (Lemma 1). We subsequently prove that input-output feedback linearization maps delta(x,u) into a state- and control-dependent additive disturbance d(z,nu) in Brunovsky canonical coordinates, bounded by ||d(z,nu)||_2 <= alpha_1 delta_bar + alpha_2 delta_bar ||nu||_2 with closed-form expressions for alpha_1 and alpha_2 (Theorem 1). This certified bound, together with a bounded input disturbance and a zero-order-hold margin, yields a compact disturbance set that seeds a robust tube-based model predictive controller. We prove that the resulting tightened quadratic program is recursively feasible, that the physical actuator limit (|u_i| <= 1100) remains inactive under an explicit sufficient condition, and that the closed-loop tracking error is Input-to-State Stable (ISS) with an asymptotic gain that is linear in delta_bar plus a term due to the exogenous input disturbance (Theorems 2 and 3).
