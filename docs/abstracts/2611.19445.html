PopulationBalanceModels.jl: An Extensible Framework for Deploying Population Balance Models

Pavan K. Inguva

arXiv:2611.19445·cs.CE·Published 2026-11-14

Population balance models (PBMs) are used to describe a diverse range of processes that have a distribution over one or more intrinsic properties. However, implementing PBMs for a new application often requires developing and verifying application-specific code for numerical solution and analysis. In this work, we present PopulationBalanceModels.jl, an open-source Julia package designed to make PBMs easy to implement. Users construct models from individual physical terms and select the numerical methods separately. Common solver and observation interfaces allow the same model to be used for simulation, Bayesian parameter estimation, and uncertainty quantification. The package currently supports various model types such as coupled and/or multi-dimensional PBMs, coupling of a PBM to a bulk mass/energy balance, and transport in an axially-dispersed plug flow reactor. While a broad range of physical terms and corresponding numerical methods are already implemented, the package is designed to support extensibility in both aspects, enabling users to incorporate new mechanisms and numerical methods into existing workflows.
