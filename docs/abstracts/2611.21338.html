Generating a simple silicon detector simulation with an open-weight large language model

Charlie H R Bamber, Ming-Liang Wong

arXiv:2611.21338·hep-ex·Published 2026-11-16

Recent LLM developments have seen AI-generated code become commonplace in the software development industry. Without tool access, LLMs cannot execute simulations, and their knowledge of toolkits such as Geant4 is limited. We demonstrate here, a detector simulation workflow with a Qwen3.6-27B model with Q4_K_M GGUF quantisation together with custom resources and tools served via MCP servers to generate a particle detector simulation. In 50 independent runs, 42(29--56)% at 95% CI produced energy-deposit distributions statistically consistent with a reference simulation, measured against a reference simulation. These results provide a proof of concept that MC simulations can be generated using text-based prompts with an LLM, given the necessary resources and tools. More extensive resources, such as example code and additional documentation, are likely to be required for more complex simulation tasks.
