quantEM: Quantitative Electron Microscopy Analysis from Differentiable Physics to Neural Priors

Colin Ophus, Arthur RC McCray, Georgios Varnavides, Stephanie M Ribet

arXiv:2611.21903·cond-mat.mtrl-sci·Published 2026-11-16

Quantitative electron microscopy includes imaging, diffraction, spectroscopy, and tomography measurements, and the analysis of these measurements increasingly requires solving inverse problems with physical forward models. Open-source software has made many of these analyses widely available, but most packages are organized around a single modality, so that multimodal analyses require moving data between packages, and new methods cannot easily reuse the physical models and optimizers of existing ones. Here we present quantEM, an open-source Python package for quantitative electron microscopy that uses PyTorch tensors for computation and automatic differentiation, and Zarr for storage. We implement each analysis method by writing a differentiable forward model and choosing a representation, loss function, constraints, and optimizer from a library of components, so that every method runs on CPUs and GPUs, can be saved and resumed, and uses the same calibrated data structures and visualization tools. We describe the current modules, including orientation and strain mapping, direct and iterative ptychography, tomography with neural representations, and X-ray and electron energy-loss spectroscopy, and show how we assemble combined methods such as ptychographic tomography from existing components. quantEM is available under the MIT license, together with documentation, tutorials, and curated example datasets.
