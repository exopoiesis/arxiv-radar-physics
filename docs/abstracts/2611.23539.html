Construction of a Deployable Hard-Constrained Turbulence Closure

Tamerlan Hajiyev, Emre Sefer, Ivan Otić, Ismail Ari, Özgür Ertunç

arXiv:2611.23539·physics.flu-dyn·Published 2026-11-17

We present a framework for constructing deployable hard-constrained turbulence closures of unclosed terms in the transport equations of Reynolds stresses and turbulent dissipation rate. The framework is built from modules, each performing a single task. The closure module represents the closure with a small network, while the state module represents the flow state during training. The closure network is coupled to the state network through the governing equation residuals, allowing the closure to be learned without reference closure values being supplied as training data. The coordinate module learns monotone input coordinates that help both networks resolve sharp changes. Within the network architecture, the boundary condition (BC) module imposes boundary values exactly using the Theory of Functional Connections, and the realizability module keeps the closure realizable. We apply the framework to decaying homogeneous isotropic turbulence (HIT) with experimental and direct numerical simulation trajectories. Here, the state module is a Deep Operator Network (DeepONet), the BC module imposes the initial state and the closure's low and high Reynolds number limits, and the realizability module ensures growth of the Taylor microscale. Across ten random seeds, the framework reduces root-mean-square seed-to-seed closure variation by about 95\% relative to the unconstrained model over the training and held-out range. The deployed 18-parameter closure network requires only the Taylor scale Reynolds number and can be exported as a standalone C function.
