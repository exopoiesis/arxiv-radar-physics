Extreme Mass Ratio Inspirals: accessing generic orbits

Ondřej Zelenka, Michal Stratený, Petr Kotlařík, Georgios Lukes-Gerakopoulos

arXiv:2611.30414·gr-qc·Published 2026-11-23

Extreme Mass Ratio Inspirals (EMRI) are a significant gravitational wave source and a target for the upcoming LISA mission. Computations of the fluxes of conserved quantities, such as energy and angular momentum, are a critical part of modeling EMRI waveforms and can be performed using a frequency domain formalism to solve the Teukolsky equation. This requires computations of large numbers of mode amplitudes, many of which are negligible. However, it is unknown ex ante which can be safely skipped. We present a machine learning approach to estimate the dominant radial mode number as a function of the remaining mode numbers and apply it to reduce the number of unnecessary computations in EMRI flux calculation.
